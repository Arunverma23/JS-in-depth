# JavaScript Interview Questions Repository 💻

This repository contains a collection of **important JavaScript interview questions**, explained in depth, to help developers prepare for interviews and strengthen their understanding of JS concepts.  

---

## Topics Overview

| Topic | Description | Example Questions / Concepts |
|-------|-------------|-----------------------------|
| JavaScript Fundamentals | Variables, data types, scope, hoisting, closures | `var vs let vs const`, scope chain, closure examples |
| Functions | Callback functions, arrow functions, higher-order functions, IIFE | `function hoisting`, `callback vs promise`, `arrow function behavior` |
| Objects & Arrays | Manipulation, iteration methods, object destructuring | `map, filter, reduce`, `Object.assign`, destructuring |
| ES6+ Features | Modern JavaScript features | `spread/rest operators`, `template literals`, modules |
| DOM & Event Handling | Selecting elements, events, bubbling & delegation | `addEventListener`, `event delegation`, `preventDefault` |
| Asynchronous JS | Promises, async/await, fetch API | `Promise.all`, `async/await`, `fetch data example` |
| JS Concepts | Prototypes, inheritance, `this` keyword, execution context | `prototype chain`, `call, apply, bind`, event loop |
| Common Interview Patterns | Coding challenges & tricky questions | `reverse a string`, `array flatten`, tricky JS behavior questions |
| Advanced Topics | Closures, currying, debouncing/throttling, event loop | `debounce function`, `currying function`, understanding event loop |
